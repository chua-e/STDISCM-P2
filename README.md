# STDISCM P2: Looking for Group Synchronization

The program manages dungeon queuing using process synchronization.

To build the program run `cargo build`
And to run the program enter `cargo run`

The `config.txt` contains the values for dungeon instances `n`, and the completion time range of `t1` and `t2`. During runtime, the program takes the user input for the total amount of tanks, healers, and DPS and creates a party of 5 consisting of 1 tank, 1 healer, and 3 DPS.
